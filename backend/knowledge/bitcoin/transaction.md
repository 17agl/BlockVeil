# Bitcoin Transaction

A Bitcoin transaction transfers control of Bitcoin from one set
of transaction outputs to another.

Transactions contain inputs and outputs.

Inputs refer to previously created outputs that are being spent.

Outputs specify an amount and spending conditions.

A transaction may contain multiple inputs and multiple outputs.

The difference between the total input value and total output
value is generally the transaction fee paid to the miner.

Bitcoin transactions are recorded on the public blockchain after
they are confirmed.
