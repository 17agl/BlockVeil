# Bitcoin Transaction Fees

Bitcoin transaction fees are paid by transaction creators to
incentivize miners to include transactions in blocks.

The fee can generally be calculated as:

transaction fee = total inputs - total outputs

Fee rates are often discussed in satoshis per virtual byte
(sat/vB).

A transaction with a higher fee rate can generally be more
attractive for inclusion when block space is limited.

The actual confirmation time depends on network conditions,
transaction fee rate, and miner selection.
