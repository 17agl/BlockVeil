# Bitcoin Address Reuse

Bitcoin address reuse means receiving multiple payments to
the same Bitcoin address.

Reusing an address can reduce privacy because observers can
associate multiple transactions with the same address.

If the same address appears repeatedly on the public blockchain,
an observer can see the transactions associated with that
address.

Address reuse does not reveal a person's real-world identity
by itself.

However, if an address becomes associated with a person or
organization through another source, the transactions associated
with that address may become easier to link.

Using a fresh receiving address for separate payments can reduce
this particular form of linkability.
